# Syllo — téléchargements

Lecteur PDF avec un tuteur IA vocal pour étudiants.

Ce dépôt ne contient que les versions à installer : choisis la dernière dans « Releases ».

- **Windows** : `Syllo-Setup-…exe`
- **Mac avec puce Apple** : le fichier `arm64.dmg`
- **Mac Intel** : le fichier `x64.dmg`
- **Linux** : le fichier `.deb` (ou l’AppImage)
